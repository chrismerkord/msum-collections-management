# MSUM Collections Management

Tools and documentation for managing the natural history collections at Minnesota State University Moorhead (MSUM).

## Data

The **Minnesota Biodiversity Atlas** is the canonical source for specimen data. This repository does not maintain a separate specimen database.

Minnesota Biodiversity Atlas exports are used as temporary inputs. Specimen data and other collection data should **not be committed to this repository**.

Catalogs, reports, and other outputs generated by these tools are derived products and are not authoritative data sources.

## Tools

Tools support:

* generating working print catalogs
* checking specimen data for errors and inconsistencies
* generating collection-management reports
* other routine collection-management workflows

## Collections

* Herbarium
* Bird collection
* Mammal collection
